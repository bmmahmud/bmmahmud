### Featured Projects

- **[AI Job Copilot — Resume Optimizer](https://github.com/bmmahmud/ai-resume-optimizer)** — Multi-agent LLM system (LangGraph, Streamlit, Gemini/Groq/Cohere) that scrapes job postings, finds resume skill gaps, iteratively rewrites resumes to hit an ATS score target, and exports tailored resumes/cover letters.
- **[Customer Shopping Trends Analysis](https://github.com/bmmahmud/customer-trends-data-analysis-SQL-Python-PowerBI)** — End-to-end retail data analytics project using SQL, Python, and Power BI to uncover customer behavior and purchase drivers.
- **[Sushi Love Restaurant Website](https://github.com/bmmahmud/sushi-love-web)** — Restaurant website built with Next.js and TypeScript.
- **[EV3 Autonomous Navigation](https://github.com/bmmahmud/ev3-Autonomous-Navigation)** — Autonomous robot navigation with collision avoidance using camera, ultrasonic, and gyro sensors in a Webots simulation.
